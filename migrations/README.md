# Описание таблиц

## Users
Таблица хранит данные пользователей:
- `id` - уникальный идентификатор пользователя в формате UUID;
- `email` - почта пользователя, покрыт уникальным индексом `idx_users_email_unique`;
- `password` - хэш пароля пользователя;
- `salt` - соль для шифрования на стороне клиента, хранится в открытом виде;
- `created_at` - отметка времени создания пользователя;
- `updated_at` - отметка времени последнего обновления пользователя;
- `deleted_at` - отметка времени мягкого удаления пользователя;

## Secrets
Таблица хранит основную информацию о секретах пользователей.
- `id` - уникальный идентификатор секрета в формате UUID;
- `user_id` - идентификатор пользователя, которому принадлежит секрет, покрыт индексом `idx_secrets_user_id`;
- `current_secret_version_id` - привязка к актуальной версии секрета (см. Secret versions), покрыт уникальным индексом `idx_secrets_current_secret_version_id`;
- `created_at` - отметка времени создания секрета;
- `updated_at` - отметка времени последнего обновления секрета;
- `deleted_at` - отметка времени мягкого удаления секрета;

## Secret versions
Таблица хранит версии секрета, которые содержат зашифрованную информацию пользователя.
- `id` - уникальный идентификатор версии секрета в формате UUID;
- `secret_id` - идентификатор секрета, которому принадлежи версия, покрыт индексом `idx_secret_versions_secret_id`;
- `version` - порядковый номер версии (от 1);
- `data_format_version` - версия формата зашифрованных данных, может использоваться на стороне клиента;
- `data_encrypted` - зашифрованные данные, расшифровываются только на стороне клиента;
- `data_size` - размер зашифрованных данных, используется только на клиенте для UI;
- `created_at` - дата создания версии секрета.

Для данной таблицы не используются метки:
- `updated_at` - обновление не поддерживается, любое изменение данных в секрете - это новая версия секрета;
- `deleted_at` - версия может быть удалена только жестко без возможности восстановления.

## Attachments
Таблица хранит бинарные данные прикрепленных к версии секрета вложений (изображения и другие файлы).
- id - уникальный идентификатор вложения в формате UUID;
- secret_version_id - идентификатор версия секрета, к которой относится вложение, покрыт индексом `idx_attachments_secret_version_id`;
- `data_format_version` - версия формата зашифрованного тела файла (устанавливается клиентом, от 1);
- `info_format_version` - версия формата зашифрованного JSON/структуры в info_encrypted (устанавливается клиентом, от 1);
- `info_encrypted` - зашифрованная информация о вложении (метаданные);
- `info_size` - размер зашифрованных данных о вложении;
- `data_encrypted` - зашифрованные данные, расшифровываются только на стороне клиента;
- `data_size` - размер зашифрованных данных, используется только на клиенте для UI;
- `created_at` - дата создания вложения.

Для данной таблицы не используются метки:
- `updated_at` - обновление не поддерживается, новый файл - новое вложение к версии секрета объект;
- `deleted_at` - вложение может быть удалена только жестко без возможности восстановления.
